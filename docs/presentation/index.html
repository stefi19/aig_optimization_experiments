Exact and Approximate Internal Correspondence Recovery After Logic Synthesis Optimization

Mapping optimized circuit nodes back to the original design

Start with the big picture: synthesis keeps the circuit behavior but changes the internal graph. The project asks how to recover the relationship between old and new internal points.

Motivation

Think of synthesis like a compiler

Software

Readable source code becomes faster machine code.

Fast, but harder to inspect.

Circuits

Readable RTL becomes optimized logic.

Smaller or faster, but internal signals move.

Final use case

The optimized netlist may show a critical path, but the engineer edits the original RTL.

We need a map back to the original design.

Use the compiler analogy because it is familiar. Then transition: for circuits, the important internal wires are like source-level variables that may disappear after optimization.

Definition

What is a digital circuit?

A digital circuit is a network of small decisions. Each decision takes 0/1 inputs and produces a 0/1 output.

Gate

A gate computes a tiny Boolean function such as AND, OR, or NOT.

Introduce gates as small Boolean functions. Keep it concrete: inputs are bits, gates produce bits, and wires connect the results.

Running example

One small circuit we reuse

n1 = a AND b n2 = n1 OR c out = n2

Internal nodes are intermediate results inside the circuit. Here, n1 and n2 are internal nodes.

Why internal nodes matter

They are the circuit's "middle steps". Optimization often changes or removes them, even when the final output stays the same.

SAT / CEC intuition

Ask: is there any input where two nodes differ?

SAT asks whether a Boolean condition can be satisfied.

CEC means combinational equivalence checking.

This is the miter idea. XOR is 1 exactly when the two functions disagree. SAT tries to find such a disagreement input.

SAT sweeping

Formal matching is stronger than simulation

  • Simulation tests selected input patterns.
  • SAT/CEC proves whether a difference exists.
  • SAT sweeping groups nodes that compute the same function.

Key idea

Simulation can miss rare differences.

SAT gives a formal yes/no for the equivalence query.

Approximate-computing lens

Not every wrong internal node is equally bad

Approximate computing uses error metrics to say how far a candidate is from the exact behavior.

For correspondence, that means separating local internal mismatch from output-visible error.

New question

Can a globally rejected internal-node candidate still be harmless, or low-error, in its circuit context?

Introduce the motivation: exact equivalence is still the strongest result, but rejected candidates can be studied with measured error. Be explicit that sampled error is not formal.

Formal metric

Global node distance

global_error_rate(f, g)
  = count_x[f(x) != g(x)] / 2^n

This compares the optimized target-node function with the original candidate-node function under aligned primary inputs, independent of contextual substitution.

Important: this is formal only when the input space is exhausted. Sampled rows are estimates.
This slide states the first equation. If the support is small, exhaustive truth-table distance is formal. If support is large, the prototype switches to deterministic sampled patterns.

Contextual metric

Output error after substitution

contextual_output_error_rate
  = count_x[Y_base(x) != Y_sub(x)] / 2^n

The substituted circuit preserves primary inputs and output ordering, then replaces one optimized node with a candidate function.

Global distance and output-visible error can diverge.

Explain that the prototype constructs a baseline optimized network and a substituted network. Output numeric error depends on BLIF output order.

Functional refactoring

When no closed region exists, factor the function

Y = F(X, Z) M = G(X) Y = H(M, Z)

The semantic boundary is no longer required to already exist as a closed optimized subgraph. It is introduced by a proven divisor and quotient.

Non-vacuity

M cannot be identity, H must depend on M, and the rewritten graph must route M to real consumers before any boundary is counted.

This is the abstraction shift after joint discovery. The goal is not another placement heuristic; it is exact functional decomposition followed by graph-active refactoring.
