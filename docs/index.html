Exact and Approximate Internal Correspondence Recovery After Logic Synthesis Optimization

This project studies how internal circuit nodes change after logic synthesis, then builds a layered flow for mapping optimized nodes back to the original design using exact, SAT-verified, and approximate correspondence.
